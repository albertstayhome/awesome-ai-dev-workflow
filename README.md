## ??ï¸?The Zero-Dependency AI Toolkit

Stop installing heavy global npm packages. Run all of these instantly from GitHub using your own Gemini API key: `export GEMINI_API_KEY="your_key"`.

### 1. Project Setup & Context Packing
* **[repo2llm](https://github.com/albertstayhome/repo2llm)** - Pack your entire codebase into a single markdown file.
  * Usage: `npx github:albertstayhome/repo2llm`
* **[mcp-filesystem-pro](https://github.com/albertstayhome/mcp-filesystem-pro)** - Expose your local filesystem to Claude Desktop via MCP.

### 2. Coding & Scaffolding
* **[ai-component-gen](https://github.com/albertstayhome/ai-component-gen)** - Generate Tailwind React components from natural language.
* **[ai-regex-pro](https://github.com/albertstayhome/ai-regex-pro)** - Generate and explain complex Regex patterns.
* **[ai-bash-pro](https://github.com/albertstayhome/ai-bash-pro)** - Translate English into executable Bash/PowerShell commands.

### 3. Testing & Localization
* **[ai-test-gen](https://github.com/albertstayhome/ai-test-gen)** - Automatically generate unit tests for your files.
* **[ai-i18n-pro](https://github.com/albertstayhome/ai-i18n-pro)** - Translate JSON i18n files into multiple languages instantly.

### 4. Code Review & Documentation
* **[ai-pr-reviewer](https://github.com/albertstayhome/ai-pr-reviewer)** - Automated AI code reviews catching security and performance flaws.
* **[ai-commit-pro](https://github.com/albertstayhome/ai-commit-pro)** - Generate Conventional Commit messages from your git diff.
* **[aio-readme](https://github.com/albertstayhome/aio-readme)** - Optimize your GitHub README for AI Search Engines (AIO).

### 5. Consumer Tools
* **[AI Cover Letter Pro](https://albertstayhome.github.io/ai-cover-letter-web/)** - 100% private, free web app to generate cover letters.
